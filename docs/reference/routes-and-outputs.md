# Routes and Outputs

**English** | [简体中文](./routes-and-outputs.zh-CN.md)

Public routes and outputs provided by the Layer. Source of truth: `src/pages/**`, `src/server/**`, and the route-rule/feature wiring in `src/modules/clarity-config/index.ts`; behavior is locked by `pnpm test:consumer` and `pnpm test:compatibility`.

## Pages

| Route | Source | Purpose |
| --- | --- | --- |
| `/` | `src/pages/index.vue` | Paginated article list, category filter, recommended articles |
| `/archive` | `src/pages/archive.vue` | Annual/category/tag archive |
| `/link` | `src/pages/link.vue` | Friend-link page rendered from `feeds.ts` |
| `/preview` | `src/pages/preview.vue` | Unpublished-article list (`content/previews/**`) |
| `/*` (catch-all) | `src/pages/[...slug].vue` | Any Content page, including articles and custom permalinks; missing paths return 404 |

A consumer page at the same Layer-relative path overrides the Layer route (see [customization](../guides/customization.md)).

## Server outputs

| Route | Source | Feature flag | Output |
| --- | --- | --- | --- |
| `GET /atom.xml` | `src/server/routes/atom.xml.get.ts` | `features.atom` | Atom feed (latest `feed.limit` posts, ordered by updated date; optional XSLT styling via `feed.enableStyle`) |
| `GET /subscriptions.opml` | `src/server/routes/subscriptions.opml.get.ts` | `features.opml` | OPML 2.0 subscriptions (own feed plus friend feeds that have a feed URL) |
| `GET /api/stats` | `src/server/api/stats.get.ts` | `features.stats` | Article count, word count, annual/category/tag statistics, scoped by `stats.includePaths` |

Disabling a feature removes its prerender rule and head wiring **and** makes the route return 404 at runtime in dev/SSR — the two semantics never diverge.

## Generated SEO outputs

| Route | Provider |
| --- | --- |
| `/robots.txt` | `@nuxtjs/seo` robots integration, fed by `article.robotsNotIndex` |
| `/sitemap.xml` | Nuxt Content sitemap schema generated by the Content factory |
| `/llms.txt` | `nuxt-llms`, configured from site metadata |
| `/favicon.ico` | Redirects to `site.favicon` |

## Route rules injected by the Theme

When a feature is enabled, the module prerenders its output with the correct content type (`application/xml` for Atom/OPML, `application/json` for stats). Consumers keep their own redirects, caching, headers, auth, and platform transforms in `nuxt.config.ts`; collisions with Theme routes must be resolved explicitly by choosing one owner.
