# Blur

[English](./blur.md) | **简体中文**

## 用途

剧透或敏感文本：模糊显示，读者悬停或触摸后显现。

## 基本语法

```md
:blur[你知道得太多了。]
```

较长段落的容器形式：

```md
::blur
多段内容作为一个区域保持模糊。
::
```

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `text` | string | 插槽回退 |

## 插槽

- `default` —— 模糊内容；回退到 `text`

## 支持的取值

普通字符串；插槽内的行内 Markdown 可用。

## 示例

```md
密码是 :blur[hunter2] —— 不要提交到仓库。
```

## 嵌套

行内形式保持行内。上游曾把 `::blur` 嵌在 `:::quote` 外；嵌套保持浅层。

## 何时使用

剧透、问答答案，或读者可能想跳过的内容。

## 何时不要使用

读者绝不能错过的内容——模糊的安全警告毫无意义。

## 常见错误

- 把普通内容整段模糊。
- 以为文本对页面源码隐藏——它只是视觉模糊。

## 支持状态

`supported` —— 源码验证；暂无兼容性基准覆盖（见审计缺口 3）。
