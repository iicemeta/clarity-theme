# Timeline

[English](./timeline.md) | **简体中文**

## 用途

垂直时间线。花括号标题行成为时间线节点，其后的块成为事件。

## 基本语法

```md
::timeline
{2026-01}

项目启动。

{2026-06}

首个版本发布。
::
```

## Props

无。

## 插槽

- `default` —— 整块文本匹配 `{…}` 的块成为 `dt` 标题；其余每块成为一个 `dd` 事件正文

## 支持的取值

花括号内任意标题文本——日期、阶段名、版本号。

## 示例

```md
::timeline
{阶段一}

盘点与梳理。

{阶段二}

Layer 抽取。
::
```

## 嵌套

事件正文接受 Markdown 与行内组件；嵌套保持浅层。

## 何时使用

年表、发布历史、迁移阶段——与标签点绑定的事件。

## 何时不要使用

有序操作说明（用列表）或无标签的分组（用标题）。

## 常见错误

- 把标题与事件写在同一行。
- 以为标题只能是日期——任意花括号文本都可以。

## 支持状态

`supported` —— 源码验证；暂无兼容性基准覆盖（见审计缺口 3）。与 Chat 一样以非标准方式读取插槽 VNode 文本；请遵守标题块约定。
