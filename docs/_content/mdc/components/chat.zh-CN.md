# Chat

[English](./chat.md) | **简体中文**

## 用途

渲染聊天记录。发言人标记写作花括号行，组件把它们映射为“标题/正文”对。

## 基本语法

```md
::chat
{.}

这是我自己的消息，显示在右侧。

{Alex}

这是 Alex 的回复。

::
```

## Props

无。

## 插槽

- `default` —— 对话内容；整块文本匹配 `{…}` 的块成为标题，其余块成为消息正文

## 支持的取值

标题标记（来源：`Chat.vue` 的 `chatRegex`）：

- `{.}` —— 作者本人（右对齐）
- `{:}` —— 系统消息
- `{Name}` —— 对方

## 示例

```md
::chat
{:}

服务于 03:00 重启。

{运维}

为什么重启了？
::
```

## 嵌套

消息正文接受 Markdown。上游曾在一条消息内嵌套 `:::div` 包装一段结构化长回复；此类嵌套保持克制。

## 何时使用

引用真实对话（支持工单、AI 对话），且文章随后会讨论它。

## 何时不要使用

为了排版而虚构的对话、FAQ 列表（用 Folding），或几条一行往复、用引用块就足够的内容。

## 常见错误

- 把标题与正文写在同一块，而不是独立成块。
- 花括号内多余空格——整块文本必须匹配 `{…}`。

## 支持状态

`supported` —— 源码验证；暂无兼容性基准覆盖（见审计缺口 3）。组件以非标准方式读取插槽 VNode 文本；请严格遵守标题块约定。
