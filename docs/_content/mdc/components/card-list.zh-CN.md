# CardList

[English](./card-list.md) | **简体中文**

## 用途

把普通 Markdown 列表变成响应式卡片网格——用于真正并列、各自独立的内容。

## 基本语法

```md
::card-list
- **快**：几分钟完成构建
- **类型安全**：端到端类型
- **分层**：一切可覆盖
::
```

## Props

无。

## 插槽

- `default` —— 要排成卡片的列表（或任意内容）

## 支持的取值

对 `ul`/`ol` 均有效；有序列表保留顺序。每个列表项内的嵌套内容渲染在卡片内部。

## 示例

```md
::card-list
1. **安装** —— 添加 Layer
2. **配置** —— 编写 `clarity.config.ts`
3. **写作** —— 使用 Markdown 与 MDC
::
```

## 嵌套

列表项可以包含行内 Markdown。避免在每张卡片里塞入大段代码围栏或其他容器。

## 何时使用

特性概览、推荐资源、选项对比——少量并列且相互独立的条目。

## 何时不要使用

读者必须按顺序执行的步骤（用正文或列表）、单个条目，或包裹文章里的每一个列表。

## 常见错误

- 期待普通段落变成卡片——内部要放列表。
- 只有两个条目也用卡片；普通列表可读性更好。

## 支持状态

`supported` —— 兼容性用例 `C-mdc` 验证。
